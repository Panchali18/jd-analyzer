# Sample data

Used by the **Try a sample** button in FitProof.

- `sample_jd.txt`: a real, public job advert (the same one as `test_data/jd_01.txt`)
- `sample_cv.txt`: a CV for a **fictional** person, written to demonstrate the app. No real person's data is used.
- `sample_result.json`: FitProof's real analysis of the two files above, generated once with Claude on Amazon Bedrock and saved, so the sample costs nothing to show.
